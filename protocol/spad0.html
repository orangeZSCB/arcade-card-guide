SPAD0 加密算法（Konami）

AIC 卡块 0（SPAD0）里 Konami access code 的加密算法。 由 HINATA 项目完整逆向（lib/core/crypto/spad0.dart）， 本文作者将其移植为 Python 并用真卡数据做了字节级验证 ✅。

算法定位

  • 不是标准密码学：没有密钥输入，是固定的查表 + 位变换混淆
  • 16 字节进、16 字节出（与 AIC 块大小一致）
  • 双向可逆（加密/解密互为逆过程）

数据结构

算法核心是三张常量表（从 HINATA 源码提取）：

表规模作用
sBox9 × 2569 组 S 盒置换
sBoxKey9 × 256与 S 盒配对的异或密钥流
hashAdd常量 5表索引步进值

前 8 组（0-7）是轮函数用的变换表，第 9 组（索引 8）用于最终收尾置换。

加密流程

输入 16 字节明文 spad[0..15]：

count = (spad[15] >> 4) + 7          # 轮数由最后一字节的高半字节决定
table = spad[15]

重复 count 轮：
    t = table % 8
    对 i = 0..14：spad[i] = sBox[t][spad[i]] ^ sBoxKey[t]   # 前 15 字节查表+异或
    前 15 字节循环左移 5 位（跨字节的位旋转）
    table += 5

收尾：
    对全部 16 字节：spad[i] = sBox[8][spad[i]] ^ sBoxKey[8]

要点：

  • 每轮用不同的表，表索引由 table 变量滚动（+5 每轮）， 而 table 的起点是明文最后一字节 → 算法对明文自敏感
  • 位旋转是跨字节的：把前 15 字节当成 120 bit 的环，整体左旋 5 bit
  • 解密是严格逆过程：先做第 9 组表的逆置换，再倒序跑轮函数 （右旋 5 位 + 逆 S 盒），轮数由密文最后一字节恢复

明文格式

SPAD0 解密后的 16 字节：

偏移 0-5   ：全零
偏移 6-15  ：20 位 access code 的 BCD

与 Aime MIFARE 块 2 的布局完全同构。

验证实例 ✅

密文：37 91 60 26 63 a0 2e c8 cd a4 a2 c0 bf c0 09 69
明文：00 00 00 00 00 00 50 14 27 88 36 45 34 65 21 26
                    → access code 50142788364534652126

另一张真卡（Konami 发行）同样字节级吻合。

实现参考

  • Dart 原版：hinata_go/lib/core/crypto/spad0.dart
  • Python 移植：本文档仓库附带 spad0_crypto.py（含命令行加解密）
