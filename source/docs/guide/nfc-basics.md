# NFC 基础：两种卡片介质

街机卡只用到两种 NFC 介质：**MIFARE Classic 1K**（ISO 14443A，13.56 MHz）和
**FeliCa Lite-S**（Sony 制，13.56 MHz，212/424 kbps）。理解它们的结构是读懂后文的前提。

## MIFARE Classic 1K

NXP（Philips）的经典产品，街机旧卡的统一介质。

### 存储结构

- 1 KB = 16 个扇区（sector 0-15），每扇区 4 个块（block），每块 16 字节
- 块编号 0-63：扇区 N 的块为 `4N .. 4N+3`
- 每扇区最后一块（4N+3）是**尾块（trailer）**：

```
偏移  内容
0-5   Key A（6 字节，永远不可读）
6-9   访问控制位 Access Bits + GPB
10-15 Key B（6 字节，视访问位可读/不可读）
```

- **块 0（扇区 0 第一块）** 是厂商块：UID + BCC + SAK + ATQA + 厂商数据。
  普通卡出厂即锁死，只有"UID 卡"（Gen1a 等魔术卡）可以改写。

### 密钥与访问控制

- 每个扇区有 Key A / Key B 两把 6 字节密钥
- 访问控制位（4 字节）决定每个块的读/写/增减需要什么密钥，
  以及尾块自身能否被修改
- 常见的街机卡配置：

| 配置 | 含义 |
|---|---|
| `FF 07 80 69` | "标准"配置：数据块双密钥可读写，尾块可用 Key B 修改 |
| `08 77 8F 11` | 预置卡配置：数据块仅 Key B 可写（本文实测的空白 AIC 卡） |

::: details 访问位解码方法
尾块字节 6/7/8 的三个比特组 C1、C2、C3 分别对应块 0-3（按位编码，字节 6 存反码）。
对数据块，C1C2C3=000 表示双密钥全权限；110 表示读 A|B、写仅 B。
对尾块，011 表示 KeyA 不可读、KeyB 可改一切。完整表格见 NXP MF1S50 数据手册。
:::

### 认证流程

读取任何块之前，必须先对该块所在扇区做认证：

```
读卡器 → 卡：  0x60/0x61（Auth A/B）+ 块号 + 密钥(6) + UID(4)
卡 ←→ 读卡器：crypto1 双向挑战
之后：        0x30 读 / 0xA0 写 该扇区的块
```

crypto1 是 NXP 的专有流密码（2008 年已被完全破解）。
**PN532 芯片内置 crypto1 引擎**，发原始认证帧即可，无需软件实现密码学。

## FeliCa Lite-S

Sony 的非接触芯片，日本交通卡（Suica）同源技术。Amusement IC 卡的介质。

### 与 MIFARE 的术语对照

| MIFARE | FeliCa | 说明 |
|---|---|---|
| UID | **IDm**（8 字节） | 芯片序列号 |
| （无） | **PMm**（8 字节） | 制造参数（厂商/型号指纹） |
| 扇区 | 服务区（service） | 用 2 字节服务码寻址 |
| 块 | 块（block） | 同样 16 字节 |
| SAK/ATQA | **系统码（syscode）** | 轮询时用于选卡 |

### Lite-S 的关键特性

- 存储：**用户区 15 块（0x00-0x0E）+ 系统区 8 块（0x80-0x87）**，共 23×16 字节
- 单系统：一张卡一个系统码
- 命令集精简，本文用到的：

| 命令 | 代码 | 作用 |
|---|---|---|
| Polling | 0x00 | 发现卡片，拿 IDm/PMm/syscode |
| Read Without Encryption | 0x06 | 明文读块 |
| Write Without Encryption | 0x08 | 明文写块 |
| Read With MAC | 0x14 类 | 带消息认证码读（需先双向认证） |
| Request Service | 0x02 | 查询服务是否存在（Lite-S 实测**无响应**） |

### 状态标志

读/写响应的尾部两个字节是状态标志（flag1, flag2）。
实测见过的组合：

| flag1 flag2 | 含义（实测语境） |
|---|---|
| `00 00` | 成功 |
| `01 A6` | 写被拒（块被锁/需要 MAC 认证） |
| `01 A8` | 块不存在（越界） |
| `01 B1` | 读需要 MAC 认证 |

::: warning
Sony 官方手册的状态码表与实测语境偶有出入，上表以 PN532 + 实卡的观测为准。
:::

### 块列表元素（Block List Element）

读写命令里用 1-2 字节的"块列表元素"指定块号。
本文工具统一使用 `[0x80, 块号]` 的两字节形式，实测对 0x00-0x87 全部有效。
