目标可行性说明

Aime 兼容卡配方（已验证）

材料：任意可写 MIFARE Classic 1K（含 UID 卡）

步骤：

  1. 探测密钥：优先试 KeyA/KeyB = FF×6 和 WCCFv2

  2. 认证扇区 0，读块 0-3 记录原状

  3. 写回测试：块 2 原样写回并比对，确认卡可写（不可写立即停手）

  4. 写入：

    块 1 = 53 42 53 44 00 00 00 00 00 00 00 00 00 00 00 00
块 2 = 00 00 00 00 00 00 <20 位 access code 的 BCD>
块 3 = FF FF FF FF FF FF FF 07 80 69 57 43 43 46 76 32

  5. 重新选卡 + KeyB WCCFv2 认证，回读三块比对

  6. 再做一次写回测试，确认写后仍可擦写

access code 选择：

  • 20 位数字，不以 3 开头
  • 推荐做法："5010000000" + decimal(UID)，天然一卡一码
  • 上私服前先在服务器面板确认该码未被占用

不要动的东西：块 0（UID）、其他扇区。尾块保持 FF 07 80 69， 否则下次自己都写不进去。

AIC 兼容卡思路（未验证）

1. 买空白可写 FeliCa Lite-S（系统码需能设为 88B4）
2. felica_backup_test backup → wtest 确认可写
3. 写入：
   - 块 00 = spad0_encrypt(00×6 + BCD access code)   # 上 Konami
   - 块 82 = IDm + DFC(自选发行方)                    # 身份证
4. SPAD1-4（Sega/Bana 区）无厂商 MAC 密钥，无法写入
   → 这类自制卡只能覆盖 Konami 场景

关键障碍在第 1 步：市售空白 FeliCa Lite-S 多为交通卡系统码， 能否写入 88B4 服务区、用户区是否上锁，需要拿到实体卡实测。

常见翻车

现象原因
写完游戏不认块 2 的 BCD 顺序写反（应大端，高位在前）
写完卡报废尾块访问位写成只读配置（如 78 77 88）
认证随机失败PN532 供电不足或天线距离太远，换 5V 稳压
nfc-mfclassic 显示成功但没写进去1.8.0 写循环 bug，用自制工具
私服显示 decimal(UID) 而不是你写的码读卡器/服务端没走 MIFARE 读取路径，查你的读卡方案
